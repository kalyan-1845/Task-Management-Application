Vortex Tasks

The ultimate premium full-stack task management application. Built for high performance, real-time collaboration, and unparalleled visual aesthetics.

Project Overview

Vortex Tasks is a complete full-stack web application designed to demonstrate mastery over modern web architecture. It implements secure JWT-based user authentication, standard CRUD task operations, collaborative commentary, and native Server-Sent Events (SSE) for zero-latency, real-time UI synchronization across all connected team dashboards.

System Architecture

Frontend: React + Vite

The client is a Single Page Application (SPA) built with React and bundled via Vite for lightning-fast HMR. It utilizes a custom-built, ultra-premium glassmorphism CSS framework, ensuring completely responsive layouts across desktop and mobile.

Backend: Node.js + Express

The server operates on a robust Node.js Express framework. It exposes RESTful API endpoints secured by JSON Web Tokens (`jsonwebtoken`) and bcrypt password hashing. It also manages the SSE connection pool.

Storage: Local JSON Database

For maximum portability and zero-installation reliability, the application uses a custom synchronous file-system JSON controller (`db.js`). This reads and writes to a `db.json` file, fully simulating a production database with strict relationship enforcement.

Real-Time Sync (SSE Engine)

Instead of relying on heavy WebSocket wrappers (like Socket.io), Vortex Tasks utilizes native browser Server-Sent Events (SSE) to achieve real-time synchronization.

// Client-side Handshake
const eventSource = new EventSource('http://localhost:5000/api/events');

eventSource.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.event === 'TASK_UPDATED') {
        updateLocalState(data.payload);
    }
};

When any user modifies a task (e.g., dragging a Kanban card to "Done"), the server broadcasts the exact state change to the entire SSE client pool, triggering an instant React re-render for all active viewers.

Key Features

  • Glassmorphism UI: Deep purple gradients, frosted blur panels, and custom glowing SVGs.
  • HTML5 Drag-and-Drop Kanban: Fluidly move tasks between custom status lanes.
  • Live Discussion Feeds: Post comments on individual tasks and watch them appear instantly on team screens.
  • Analytical Dashboards: Pure CSS and SVG-based circular progression dials and priority charts.
  • Calendar Grid Pre-population: Click any blank day on the calendar to instantly spawn a new task prepopulated with that due date.
  • Advanced List Filters: Dynamic sorting and status checkboxes optimized for rapid workflows.

Installation & Setup

The workspace includes a master package.json that utilizes the concurrently module to boot both servers flawlessly.

1. Install Dependencies

npm run install-all

2. Start the Workspace

npm run dev

This command will expose the Frontend at http://localhost:5173 and the Backend at http://localhost:5000.

API Reference

All endpoints are prefixed with /api. Protected routes require an Authorization: Bearer header.

Auth Routes

  • POST /auth/register - Create a new user
  • POST /auth/login - Authenticate and retrieve JWT
  • GET /auth/me - Verify token and get user profile (Protected)

Task Routes (Protected)

  • GET /tasks - Retrieve all active tasks
  • POST /tasks - Create a new task
  • PUT /tasks/:id - Update task properties (status, priority, etc.)
  • DELETE /tasks/:id - Remove a task and its comments

Live Streams (Protected)

  • GET /events - Initialize persistent SSE stream
